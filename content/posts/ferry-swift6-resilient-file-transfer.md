## 为什么在这个时代，我们依然需要一款全新的 SFTP 客户端？

在日常管理远程服务器、同步开发测试集群或备份云端大文件时，文件传输工具是工程师每分每秒都在交互的命脉工具。

然而，打开 macOS 上现存的经典客户端（如 FileZilla、Cyberduck 等），体验往往让人崩溃：
1. **老旧非原生的 Java/C++ 界面**：高分辨率视网膜屏幕下滚动卡顿、无法响应 macOS 现代交互手势，缺乏 macOS 15+ 现代审美质感；
2. **并发数据竞争与闪退**：多任务传输一旦遇到网络波动，整个 App 界面瞬间冻结（UI 卡死），甚至由于线程冲突导致任务列表直接崩溃丢弃；
3. **静默覆盖的噩梦**：两端修改发生冲突时，缺乏严格可视化的差异比对决策（DiffPlan），一不小心就会把生产服务器的新代码彻底覆盖。

作为追求极致确定感和视觉洁癖的开发者，我受够了将就。**Ferry** 由此诞生 —— 它的核心信条只有一条：**“核心零 C 依赖、传输严格防御、用户数据零丢失”**。

## 核心架构设计与工程突破

```
┌────────────────────────────────────────────────────────┐
│             SwiftUI + AppKit 双栈混合界面                │
│    多连接会话标签栏 (Tabs)   │  双栏原生极速文件树 (Finder 体验)   │
└───────────────────────────▲────────────────────────────┘
                            │ (严格主线程隔离与双向拖拽)
┌───────────────────────────┴────────────────────────────┐
│          Swift 6 严格并发传输调度器 (TaskGroup)           │
│   每任务独立故障隔离  │  双向独立带宽限速  │  指数退避自愈   │
└───────────────────────────┬────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────┐
│               核心传输引擎与协议矩阵 (Core Engine)        │
│   RelayEngine 跨服务器直传   │   3-Way DiffPlan 冲突真值表  │
│   libssh2+OpenSSL3 (SFTP)   │   libcurl + TLS 1.3 (FTPS)   │
└────────────────────────────────────────────────────────┘
```

### 1. Swift 6 严格并发（Strict Concurrency）架构
Ferry 从底层网络契约到顶层 UI 交互完全拥抱 Swift 6 严格并发模型。
- 通过 `@MainActor` 隔离所有 UI 绘制；
- 每一个上传/下载任务均运行在独立的结构化并发 `TaskGroup` 中，单任务网络异常绝不会击溃其它传输流；
- 彻底根除传统多线程网络库中的数据竞争（Data Race），在万级小文件并发传输时内存占用依旧稳定平缓。

### 2. RelayEngine：跨服务器流式中继直传
在传统工作流中，如果想把 Server A 的 50GB 数据迁移到 Server B，通常需要先下载到本地 Mac 磁盘，再从 Mac 上传到 Server B —— 既浪费本地 SSD 寿命，又白白消耗双倍带宽。

在全新发布的 **1.0.0-beta.2** 中，Ferry 引入了 **RelayEngine 服务器直传工作台**：
- 支持建立直连流式中继管道，本地仅作为控制流指挥枢纽，数据在两台远端服务器间直接飞渡；
- 避免了本地磁盘 I/O 写入与空间占用，跨云数据迁移速度翻倍。

### 3. 3-Way 三方同步与 DiffPlan 冲突真值表
在同步模式下，Ferry 绝不采取激进的“静默覆盖”策略。
- 采用三方比对（本地、远端、上次基线）计算出状态真值表；
- 生成可视化的 DiffPlan 执行计划，清晰标明上行覆盖、下行拉取或冲突警告，只有在用户明确授权下才执行不可逆操作。

### 4. 专为 macOS 度身定制的现代细节
- **全模式凭据认证**：密码自动存入 macOS 登录钥匙串 Keychain，全面支持 OpenSSH 格式私钥、加密口令私钥与本地 `ssh-agent` 转发；
- **Finder 双向拖拽矩阵**：完美支持与系统访达的双向直接拖拽、Promise 延迟下载与空格键 Quick Look 极速预览；
- **弹性流控与定时任务**：支持上行与下行独立带宽限速，并提供夜间低峰期定时备份传输能力。

## 结语

一个好工具的标准，不是功能堆砌，而是在最关键的时刻给你**“绝对靠谱”**的掌控感。Ferry 的每一个像素与每一行并发逻辑，都为了让 macOS 用户在每一次敲下传输键时，拥有极致的从容与优雅。
